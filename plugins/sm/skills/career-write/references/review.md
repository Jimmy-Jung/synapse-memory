# 검토자료.md 구성

작성자: JunyoungJung · 작성일: 2026-09-22

이 문서는 작성 규칙이다. 실제 결과에는 해당하는 절만 채우고 빈 표·치환 슬롯·작성 지침을 남기지 않는다. 분리된 본문과 같은 작업 폴더에 저장한다.

## 작성 조건

문서 종류, 독자·게시 또는 제출 위치, 언어·분량, 참조한 기준 문서와 사실 기준 시점을 적는다. 제출 양식이 없으면 이를 별도로 지어내지 않는다.

## 사용한 경험과 근거

주장별로 본문의 위치, 원자료 상대 링크·절 또는 공개 URL, 개인 역할과 팀 결과, 측정 조건, 확인 상태를 기록한다. 선택한 경험을 왜 앞에 배치했는지도 설명한다. 사용자 답변은 필요한 사실의 짧은 요약과 확인일만 남긴다.

## 확인할 사항

서로 다른 주장과 각 출처, 아직 모르는 내용, 본문에서 제외하거나 범위를 좁힌 처리, 필요한 질문을 적는다. 질문이 글 구성을 막는지 후속 보완인지 구분한다. 해결되면 답변과 실제 반영 내용을 갱신하고, 단순 표현 완화를 사실 확인으로 기록하지 않는다.

## 회사 조사와 지원 전략

회사 맞춤 작업에서만 추가한다. 회사·공고 출처와 확인일, 실제 확인한 내용과 추론, 요구사항과 경험 매칭, 약한 근거와 경험 공백, 강조·제외 이유를 적는다. 닫힌 공고·접근 실패·조사하지 못한 항목은 확인 범위로 남긴다.

## 검토 결과

역할 귀속, 수치 조건, 완료 상태, 문서별 어조·구성, 요구 분량, 표준 Markdown·링크, 공개 범위를 실제로 점검한 결과를 적는다. 본문 상태가 초안인지 사용자 승인을 받은 것인지 구분한다. 체크했다는 사실과 외부에서 검증됐다는 주장을 혼동하지 않는다.
